# SLX Explorer

Interactive English presentation of “Separating Common-Factor from Covariate-Specific Spillovers: An Exact SLX Score-Test Decomposition”, by Marcos Herrera-Gómez.

Open index.html locally, or publish this folder's contents with GitHub Pages. No build or installation is required. Math is rendered using native MathML in modern browsers.

## Publish
Upload index.html, paper.pdf, results.csv, .nojekyll and this README to the repository root. In Settings → Pages choose Deploy from a branch, main, / (root), then Save. Use the URL returned by GitHub Pages. The archive contains the files at its root; upload the extracted files, not the ZIP itself.

## Provenance
The narrative follows the supplied manuscript. Statistics are transcribed from Table 6, p. 19. St. Louis swλ is 0.01 in the rounded table and 0.015 in the discussion. The web page does not re-estimate models. The slxos package includes the empirical data and replication code, as clarified by the author. Repository and DOI links are taken from the manuscript and were not independently verified. Numerical results and scientific qualifications are unchanged from the Spanish presentation.
